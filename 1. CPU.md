# Ciclo da CPU:
- Funciona praticamente só com fetch (busca de dados) e execute (executar)

- Program Counter (PC): guarda o endereco da proxima operacao.
	EX: quando o processador ta no porcesso 200, ele ja guarda a localzacao da memoria do 201

- Memory Adress Register (MAR): ele manda o endereco da memoria pra ram, pega do PC e manda pra ram.
	EX: manda o 201 q tava no pc e manda pra ram

- Memory Buffer Register (MBR):  
	EX: depois q a ram pegou o conteudo que o MAR mandou a localizacao, a ram joga pro MBR 

- Intruction Register (IR): depois de todo o ciclo, é aonde fica o processo para ser executado.
	EX: vem do MBR e fica como ponte pra CPU e vai para o processo 202
