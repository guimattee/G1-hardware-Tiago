# Pirâmide da hierarquia de memória:

1. Resgitradores (topo da pirâmide):
	velocidade: ultra-rapida (0 ciclo de atraso)
	tamanho: minimo (bytes)
	custo: carissimo

2. Memória cache (L1, L2, L3):
	Velocidade: muito rapida
	tamanho: pequeno (MB)

3. Memória RAM (memória principal):
	velocidade: média (cpu precisa parar para conseguir achar o que precisa)
	tamanho: grande (GB)
	volatil: perde tudo quando desliga o pc

4. SSD:
	velocidade: lenta comparado à ram
	tamanho: gigante (GB - TB)
	nao volatil: guarda os dados ate sem energia

# Memória virtual: 
	Quando a memória RAM enche, o sistema operacional usa um pedaco do ssd para armazenar e fingir que é tam (chamado de swap ou arquivo de paginacao).
	Como a velocidade do ssd é muito menor q o ssd, causa gargalos para o que for precisar dela.

# Taxonomia de Flynn (classificação do paralelismo):
3 siglas usadas para separar o tipo de instrução de dados entre processadores:

1. SISD (Single Instruction, Single Data): O computador antigo, 1 instrução por vez (1 núcleo);

2. SIMD (Single Instruction, Multiple Data): Uma instrução é aplicada em vários dados ao mesmo tempo.
	EX: Se você quer aumentar o brilho de uma foto, quando aplicar o aumento vai mexer em milhões de pixeis ao mesmo tempo.

3. MIMD (Multiple Instruction, Multiple Data): Múltiplas instruções diferentes rodando em múltiplos dados diferentes.
	EX: Processadores Multi-core. Cada núcleo está rodando um programa diferente.

# Arquitetura UMA e NUMA (memória compartilhada):
quando tem vários processadores, como eles acessam a RAM:

- UMA (Uniform Memory Acess - acesso uniforme): 
	- Todos processos ligados à RAM pelo mesmo barramento;
	- Todos levam o mesmo tempo para acessar qualquer endereço da memória.

- NUMA (Non-Uniform Memory Acess acesso não uniforme):
	- Cada processador tem seu bloco de RAM;
	- Acessar a RAM do seu bloco é muito rápido, mas acessar de outro processador (remota) é mais lento
