# CISC (Complex Instruction Set Computer):
faz várias instruções dificeis

- muitas instrucoes diferentes;
- tamanho variavel da instrucao (1 a 17);
- poucos registradores proprios;
- podem acessar a ram direto;

Usado em processadores x86 (intel, ryzen) de alto desempenho

# RISC (Reduced Instruction Set Computer):
instrucoes simples mas que faz rapido

- instrucoes simples e diretas;
- tamanho padronizado (32 bits);
- operacoes matematicas so acontecem no proprio processador (registradores), para salvar, buscar na ram é necessário o LOAD e o STORE;
- feito para executar em fila

Usado em ARM (celulares, raspberry)
